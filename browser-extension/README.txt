RespawnSwitch 抖音网页连接器（Chrome / Microsoft Edge）

1. 地址栏打开 chrome://extensions/ 或 edge://extensions/。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件所在 browser-extension 文件夹。
4. 提前打开且只保留一个 https://www.douyin.com/ 视频标签页。
5. 启动 RespawnSwitch，选择“自动选择”或“Chrome / Edge 网页”。

扩展只匹配 douyin.com，并只连接本机 127.0.0.1:17653；不读取 Cookie、密码、浏览历史或其他网站。
