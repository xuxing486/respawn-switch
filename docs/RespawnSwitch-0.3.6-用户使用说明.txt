RespawnSwitch 0.3.6 用户使用说明
作者：Stress Monster

一、开始

1. 完整解压压缩包，双击 RespawnSwitch.exe。
2. 启动并登录英雄联盟，游戏显示模式使用“无边框”。
3. 提前打开抖音客户端；或在 Chrome / Edge 打开一个抖音视频，并按 browser-extension/README.txt 安装随包扩展。
4. 点击桌宠底部状态胶囊展开面板；抖音来源通常保留“自动选择”。
5. 面板显示“准备就绪”后进入对局。首次使用建议在训练模式测试一次。

二、游戏中

- 阵亡：切到抖音、静音英雄联盟；置顶悬浮窗显示英雄、K/D/A 和连续复活倒计时。
- 复活：先暂停抖音，再返回英雄联盟，最后恢复英雄联盟原来的声音。
- 程序只改英雄联盟声音，不会静音抖音、系统或其他程序。

三、桌宠

- 平时只显示约 155×205 的 Q 版小桌宠，不会保留成人版大小的透明挡操作区域。
- 单击底部状态：扩展为成人版形象和完整面板；关闭面板后立即恢复小 Q 版。
- 拖动身体空白处：移动桌宠；靠近屏幕边缘会吸附，离开后会探出一小部分。
- 摸头：开心回应；碰左手：击掌；碰尾巴：害羞回应。
- 双击桌宠：打开成人版面板。托盘图标可以再次显示或退出程序。

四、问题

- 等待游戏：确认英雄联盟客户端已经登录。
- 等待抖音：打开一个视频并先手动播放一次，再点“重新检查”。
- 抖音没有显示到游戏上面：让游戏、抖音和本程序以相同权限启动，并确认游戏使用无边框模式。
- 返回后抖音仍播放：先手动暂停并保留现场；下一次打开程序会重新建立精确媒体连接。
- 返回后游戏无声音：退出本程序后检查 Windows 音量合成器中的英雄联盟静音状态。

Firefox 暂不支持。程序不读取游戏内存、不注入、不模拟空格键，也不使用全局鼠标/键盘钩子。
