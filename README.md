# RespawnSwitch 0.3.0

RespawnSwitch 是 Windows x64 本地工具：League 英雄阵亡时切换到抖音并显示英雄、K/D/A 和复活倒计时；英雄复活后暂停抖音并恢复游戏。

## 0.3.0

- 不再扫描磁盘或猜测抖音安装路径，用户使用前自行打开抖音。
- 桌面抖音通过唯一窗口和定向 GSMTC 会话执行并验证 Play/Pause。
- Chrome / Microsoft Edge 网页版通过随包 Manifest V3 扩展，精确控制唯一 `douyin.com` 标签页的可见视频；Firefox 暂不支持。
- 复活时间每次阵亡只建立一个时间锚点，随后使用单调时钟进行 100ms 本地刷新；Riot 存活状态仍负责最终复活确认。
- 悬浮层显示当前英雄、K/D/A、连续倒计时和连接状态。
- 新主界面在进入游戏前分别显示 League 客户端、抖音目标、媒体控制和自动流程是否就绪，并将故障归属到具体组件。
- 外部窗口/媒体工作与 250ms 游戏采样解耦，避免抖音连接失败卡住阵亡/复活监控。

## 使用

1. 从交付包完整解压 `RespawnSwitch-0.3.0-win-x64.zip`，双击 `RespawnSwitch.exe`；无需预装 .NET 或管理员权限。
2. 启动并登录 League 客户端，将游戏显示模式设为“无边框”。
3. 桌面模式：提前打开抖音视频；网页模式：按 `browser-extension/README.txt` 安装扩展，并且只保留一个抖音视频标签页。
4. 主界面显示“赛前准备完成”后进入游戏。首次使用请在训练模式验证完整阵亡/复活周期。

详细步骤见 [`docs/RespawnSwitch-0.3-快速使用.txt`](docs/RespawnSwitch-0.3-快速使用.txt)。

## 安全边界

- 只读取 Riot 官方本机 Live Client Data；赛前只通过进程/窗口确认 League 客户端存在，不使用不受支持的私有 LCU API。
- 不读取游戏内存、不注入、不模拟键鼠、不发送空格键或全局媒体键。
- 浏览器桥接只绑定 `127.0.0.1`；扩展不读取 Cookie、密码、浏览历史或其他网站。
- 任何窗口、媒体会话或网页标签不唯一时均失败关闭，不猜测控制目标。

自动化构建和 169 项测试已通过，但 League、抖音及浏览器会持续更新，实际当前版本的端到端行为仍需在本机训练模式验证。
