# RespawnSwitch 0.3.6

Created by **Stress Monster**.

RespawnSwitch 是 Windows x64 本地工具：League 英雄阵亡时切换到抖音并显示英雄、K/D/A 和复活倒计时；英雄复活后暂停抖音并恢复游戏。

## 0.3.6

- 修复偶发“复活后抖音没有暂停”和进入/返回互相抢状态：每次阵亡拥有独立媒体、网页、窗口和音频资源；复活后禁止任何迟到 Play 再提交。
- 桌面抖音 Pause 现在会短时轮询实际状态；第一次明确 Pause 未落地时只补发一次明确 Pause，仍不使用空格或 Toggle。
- 返回顺序固定为：暂停抖音 → 还原抖音窗口 → 切回 League → 恢复 League 音量。单项失败不会跳过后续恢复。
- 主界面变成透明、无边框、可拖动并可贴边探出的原创 Q 版猫娘桌宠；点状态胶囊展开简洁面板，摸头、碰手、碰尾巴有不同台词和动画。
- 技术日志继续隐藏；英雄、K/D/A 与复活倒计时仍由独立置顶悬浮窗显示。

## 0.3.5

- 切换到抖音时，只静音当前 League 游戏进程的音频会话；抖音、系统音量和其他程序不受影响。
- 复活并切回 League 时，恢复程序实际静音过的游戏音频；用户原本已静音的会话保持静音。
- 程序退出、切换失败或复活与静音并发发生时也会执行安全恢复；主界面与既有窗口、媒体、倒计时逻辑不变。

## 0.3.4

- 主界面重做为成熟、克制的二次元猫娘风格，保留深色质感与轻微动效，不采用儿童化文案。
- 首页只显示英雄联盟、抖音和总体状态；GSMTC、Automation、窗口类等术语移入开发者说明。
- 错误提示改为用户可直接执行的中文，明确指出应检查游戏还是抖音。
- 从本版起同时提供用户使用说明与开发者说明，并在程序、扩展、素材和交付包中写入 `Stress Monster` 署名。

## 0.3.3

- 悬浮窗在本地 100ms 倒计时刷新时重新确认自身位于 Topmost 带顶部，同时继续保持无激活、鼠标穿透和原位置。

## 0.3.2

- 不再把 Win32 请求返回值当作成功；现在读取可见、最小化、前台/置顶和窗口边界，确认切换真实完成。
- 复用赛前保存的抖音窗口类和 GSMTC 媒体标识，并行执行窗口切换与播放，移除阵亡热路径中的全窗口重复签名读取。
- 正确保存最小化窗口的正常还原位置，兼容 DWM 无边框边界差异。

## 0.3.1

- 对局接口短暂失联时显示“连接不稳定”，恢复后自动回到已连接状态。

## 0.3.0

- 不再扫描磁盘或猜测抖音安装路径，用户使用前自行打开抖音。
- 桌面抖音通过唯一窗口和定向 GSMTC 会话执行并验证 Play/Pause。
- Chrome / Microsoft Edge 网页版通过随包 Manifest V3 扩展，精确控制唯一 `douyin.com` 标签页的可见视频；Firefox 暂不支持。
- 复活时间每次阵亡只建立一个时间锚点，随后使用单调时钟进行 100ms 本地刷新；Riot 存活状态仍负责最终复活确认。
- 悬浮层显示当前英雄、K/D/A、连续倒计时和连接状态。
- 新主界面在进入游戏前分别显示 League 客户端、抖音目标、媒体控制和自动流程是否就绪，并将故障归属到具体组件。
- 外部窗口/媒体工作与 250ms 游戏采样解耦，避免抖音连接失败卡住阵亡/复活监控。

## 使用

1. 从交付包完整解压 `RespawnSwitch-0.3.6-win-x64.zip`，双击 `RespawnSwitch.exe`；无需预装 .NET 或管理员权限。
2. 启动并登录 League 客户端，将游戏显示模式设为“无边框”。
3. 桌面模式：提前打开抖音视频；网页模式：按 `browser-extension/README.txt` 安装扩展，并且只保留一个抖音视频标签页。
4. 主界面显示“准备就绪”后进入游戏。首次使用请在训练模式验证完整阵亡/复活周期。

基础步骤见 [`docs/RespawnSwitch-0.3.6-用户使用说明.txt`](docs/RespawnSwitch-0.3.6-用户使用说明.txt)，技术细节与已知限制见 [`docs/RespawnSwitch-0.3.6-开发者说明.md`](docs/RespawnSwitch-0.3.6-开发者说明.md)。

## 安全边界

- 只读取 Riot 官方本机 Live Client Data；赛前只通过进程/窗口确认 League 客户端存在，不使用不受支持的私有 LCU API。
- 不读取游戏内存、不注入、不模拟键鼠、不发送空格键或全局媒体键。
- 浏览器桥接只绑定 `127.0.0.1`；扩展不读取 Cookie、密码、浏览历史或其他网站。
- 任何窗口、媒体会话或网页标签不唯一时均失败关闭，不猜测控制目标。

自动化构建和测试已通过，但 League、抖音及浏览器会持续更新，实际当前版本的完整阵亡/复活行为仍需在本机训练模式验证。
