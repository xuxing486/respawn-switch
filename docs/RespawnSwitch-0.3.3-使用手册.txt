RespawnSwitch 0.3.3 使用手册

一、准备与启动
1. 完整解压 RespawnSwitch-0.3.3-win-x64.zip，双击 RespawnSwitch.exe；无需安装 .NET 或管理员权限。
2. 启动并登录 League 客户端。主界面显示“已检测 · 可以赛前准备”即客户端检查成功。
3. 将游戏画面设为“无边框”；窗口化也可使用，独占全屏不属于支持范围。
4. 提前打开抖音桌面客户端并打开一个视频，建议先手动播放/暂停一次。
5. 软件内选择“自动选择”或“桌面客户端”。“桌面客户端已检测”且“GSMTC Play / Pause 已验证”表示准备完成。
6. 进入对局后，“对局数据”应自动变为“已连接 · 当前存活”或“已连接 · 当前阵亡”。

二、Chrome / Microsoft Edge 抖音网页
1. 按 browser-extension\README.txt 安装随包扩展。
2. 提前打开且只保留一个 douyin.com 视频标签页。
3. 软件内选择“自动选择”或“Chrome / Edge 网页”。
4. “浏览器扩展 Play / Pause 已连接”表示准备完成。Firefox 暂不支持。

三、自动行为
- 阵亡：立即显示英雄、K/D/A 和本地连续倒计时；同时播放抖音，并把抖音恢复、激活和置于无边框 League 之上。
- 悬浮窗：每 100ms 更新一次倒计时，并持续保持在抖音和其他普通页面之上；不抢焦点、鼠标可穿透。
- 复活：先暂停抖音，恢复抖音原来的大小、位置、最小化及置顶状态，再切回 League。
- 已保存的窗口类和媒体标识会在后续阵亡时直接复用；缓存失效才重新校准。
- 主界面会把问题标记为 League、抖音桌面、抖音网页、媒体或窗口问题。

四、常见问题
1. “未检测到 League 客户端”：启动并登录 League 客户端，再点击“重新检测连接”。
2. 已进入游戏仍在等待：确认运行的是 0.3.3，并确认游戏内能访问 Riot Live Client Data。
3. “连接不稳定”：League 本地 2999 对局接口暂时无响应；软件会继续重试。
4. “桌面客户端未检测”或“媒体未就绪”：提前打开抖音视频并手动播放/暂停一次，确保只有一个抖音媒体会话。
5. “topmost-not-confirmed”：Windows 未允许抖音成为前台或置顶窗口；确认抖音与 League 使用相同权限级别，然后重启三者。
6. 网页版“no-tab”或“multiple-tabs”：只保留一个 douyin.com 视频标签页并确认扩展已启用。
7. 无法返回 League：确认使用无边框模式，且 League、抖音和本工具没有一个被单独设为管理员运行。
8. 悬浮倒计时未显示：确认运行的是 0.3.3；0.3.2 会被后置顶的抖音窗口覆盖。
9. “正在确认复活”：倒计时已归零，软件正在等待 Riot 数据确认真正复活。

五、兼容与安全范围
- 版本：RespawnSwitch 0.3.3，Windows x64 自包含版。
- 系统：Windows 10 1809 或更高版本。
- 浏览器：Chrome、Microsoft Edge；Firefox 暂不支持。
- 数据：Riot Live Client Data 只在正式进入对局后可用；赛前只确认 League 客户端存在。
- 安全：不读游戏内存、不注入、不模拟按键、不扫描电脑磁盘；窗口只在路径、签名和窗口类校验后控制。
