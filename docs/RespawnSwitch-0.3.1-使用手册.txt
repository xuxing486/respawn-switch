RespawnSwitch 0.3.1 使用手册

一、准备与启动
1. 完整解压 RespawnSwitch-0.3.1-win-x64.zip，双击 RespawnSwitch.exe；无需安装 .NET 或使用管理员权限。
2. 启动并登录 League 客户端。主界面显示“已检测 · 可以赛前准备”即客户端检查成功。
3. 游戏画面必须使用“无边框”模式；独占全屏不属于支持范围。
4. 进入对局后，“对局数据”应自动变为“已连接 · 当前存活”或“已连接 · 当前阵亡”。

二、抖音桌面客户端
1. 提前启动抖音并打开一个可播放视频，建议先手动播放/暂停一次。
2. 软件内选择“自动选择”或“桌面客户端”。
3. “桌面客户端已检测”且“GSMTC Play / Pause 已验证”表示准备完成。

三、Chrome / Microsoft Edge 抖音网页
1. 按 browser-extension\README.txt 安装随包扩展。
2. 提前打开且只保留一个 douyin.com 视频标签页。
3. 软件内选择“自动选择”或“Chrome / Edge 网页”。
4. “浏览器扩展 Play / Pause 已连接”表示准备完成。Firefox 暂不支持。

四、自动行为
- 阵亡：读取一次复活时间锚点，悬浮显示英雄、K/D/A 和连续倒计时；切到抖音并验证 Play。
- 复活：验证 Pause，收起悬浮层，再恢复 League。
- 主界面会把问题标记为 League、抖音桌面、抖音网页、媒体或窗口问题。

五、常见问题
1. “未检测到 League 客户端”：启动并登录 League 客户端，再点击“重新检测连接”。
2. 已进入游戏但仍显示“等待进入游戏”：确认运行的是 0.3.1；0.3.0 存在前端未接收首次存活同步事件的问题。
3. “连接不稳定”：League 本地 2999 对局接口暂时没有响应；软件会继续重试，恢复后自动显示已连接。
4. “桌面客户端未检测”或“媒体未就绪”：提前打开抖音视频并手动播放/暂停一次，确保只有一个抖音媒体会话。
5. 网页版“no-tab”：只打开一个 douyin.com 视频标签页，并确认扩展已启用。
6. 网页版“multiple-tabs”：关闭多余抖音标签页。
7. 无法返回 League：确认游戏使用无边框模式。
8. “正在确认复活”：本地倒计时已经归零，软件正在等待 Riot 数据确认真正复活。

六、版本与兼容范围
- 版本：RespawnSwitch 0.3.1，Windows x64 自包含版。
- 系统：Windows 10 1809 或更高版本。
- 浏览器：Chrome、Microsoft Edge；Firefox 暂不支持。
- 数据：Riot Live Client Data 只在正式进入对局后可用；赛前只确认 League 客户端存在。
- 安全：不读游戏内存、不注入、不模拟按键、不扫描电脑磁盘。
