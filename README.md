# RespawnSwitch 0.2.0

RespawnSwitch 是一个 Windows x64 本地工具：在 League of Legends 英雄阵亡时显示无边框置顶复活倒计时，并打开抖音；英雄复活后暂停桌面版抖音、恢复其窗口状态，再将焦点切回游戏。

## 0.2.0 新功能

- 自动确认抖音客户端位置：先检查已保存路径、运行进程、注册表和开始菜单，再扫描电脑上的全部本机固定磁盘。
- 全盘扫描在后台运行，可查看已扫描文件夹、跳过目录和候选数量，也可随时取消或重新扫描。
- 扫描不会进入移动磁盘、网络磁盘或目录联接点；无权限目录会安全跳过。
- 候选文件需通过文件名、产品信息、版本和签名元数据验证，不会在验证阶段执行未知文件。
- 找不到可信客户端、扫描尚未完成或候选结果不唯一时，可自动打开固定官网 `https://www.douyin.com/`。
- 可选择“自动”“手动”“仅网页版”三种模式；网页版每次阵亡周期最多打开一次，复活时不会发送全局媒体暂停。
- 新版深色卡片界面提供状态卡、路径设置、候选列表、扫描进度和事件记录。

## 使用

1. 解压 `RespawnSwitch-0.2.0-win-x64.zip`，双击 `RespawnSwitch.exe`。程序为自包含版本，不要求预装 .NET，也不需要管理员权限。
2. 将 League 设置为“无边框”或“窗口化”模式。
3. 首次启动后等待抖音扫描完成；也可手动选择 `douyin.exe`，或切换为“仅网页版”。
4. 保持 RespawnSwitch 运行并进入游戏。阵亡时会显示倒计时并执行当前抖音策略；复活后会恢复游戏。

## 边界

- 网页版回退仅负责打开官网，不会控制浏览器内视频的暂停状态。
- 全盘扫描耗时取决于磁盘容量、文件数量与权限；扫描期间主界面仍可使用。
- 项目包含自动化构建、单元测试、窗口测试和自检，但 League、抖音版本、浏览器策略及本机窗口环境可能变化，首次使用时建议在训练模式验证一次完整阵亡/复活流程。
