RespawnSwitch 0.3.5 用户使用说明
作者：Stress Monster

一、开始前

1. 完整解压压缩包，不要直接在压缩包里运行。
2. 打开并登录英雄联盟。
3. 打开抖音客户端，或用 Chrome / Edge 打开一个抖音视频。
4. 双击 RespawnSwitch.exe。
5. 在“抖音来源”中保留“自动选择”，或选择你实际使用的版本。
6. 看到“准备就绪”后再进入对局。

二、游戏中

- 阵亡后：程序会切到抖音、静音英雄联盟，并在最上方显示英雄、K/D/A 和复活倒计时。
- 复活后：程序会暂停抖音、返回英雄联盟，并恢复游戏原来的声音状态。
- 只会静音英雄联盟，不会静音抖音、系统或其他程序。
- “预览悬浮窗”可以在赛前检查悬浮窗是否正常显示。

三、网页抖音第一次使用

1. 在 Chrome 或 Edge 打开“扩展程序”页面。
2. 打开“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择程序目录中的 browser-extension 文件夹。
5. 只保留一个正在播放视频的抖音标签页。

四、遇到问题

- 显示“等待游戏”：确认英雄联盟已启动并登录。
- 显示“等待抖音”：打开一个视频并手动播放一次，再点“重新检查”。
- 抖音没有盖到游戏上方：让英雄联盟、抖音和本程序使用相同权限启动。
- 返回游戏后没有声音：先退出本程序；程序退出时会再次尝试恢复它改动过的游戏音频。仍未恢复时，在 Windows 音量合成器中取消英雄联盟静音。
- 首次使用建议在训练模式完整测试一次阵亡和复活。

Firefox 暂不支持。程序不读取游戏内存，也不会模拟空格键。
