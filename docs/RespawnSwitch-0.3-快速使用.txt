RespawnSwitch 0.3.0 快速使用

一、准备
1. 解压整个 ZIP，双击 RespawnSwitch.exe；无需安装 .NET。
2. 启动并登录 League 客户端。主界面显示“已检测 · 可以赛前准备”即成功。
3. 游戏画面请使用“无边框”模式。

二、使用抖音桌面客户端
1. 提前启动抖音并打开一个可播放视频，建议先手动播放/暂停一次。
2. 软件内选择“自动选择”或“桌面客户端”。
3. “桌面客户端已检测”且“GSMTC Play / Pause 已验证”即准备完成。

三、使用 Chrome / Microsoft Edge 抖音网页
1. 按 browser-extension\README.txt 安装随包扩展。
2. 提前打开且只保留一个 douyin.com 视频标签页。
3. 软件内选择“自动选择”或“Chrome / Edge 网页”。
4. 显示“浏览器扩展 Play / Pause 已连接”即准备完成。Firefox 暂不支持。

四、自动行为
- 阵亡：读取一次复活时间锚点，悬浮显示英雄、K/D/A 和本地连续倒计时；切到抖音并验证 Play。
- 复活：验证 Pause，收起悬浮层，再恢复 League。
- 主界面会把问题明确标记为 League、抖音桌面、抖音网页、媒体或窗口问题。

注意：Riot Live Client Data 只在正式进入对局后可用；赛前仅确认 League 客户端已经启动并登录。软件不读游戏内存、不注入、不模拟游戏按键，也不会全盘扫描电脑。
